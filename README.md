# Каталог тем взаємопідтримки · Neurolutionary

Інтерактивна пропозиція каталогу для перегляду власником, 09.10.2026.

144 конкретні теми → 36 підрозділів → 12 життєвих категорій.

Версія 3: **576 конкретних варіантів безоплатної допомоги**, по чотири у кожній темі.

- Одна картка, два незалежні набори: «Можу підтримати» та «Шукаю підтримку».
- У кожному наборі 1–3 конкретні варіанти допомоги на весь розділ. Одна тема або дія може входити до обох наборів.
- Категорії → підрозділи → теми → конкретні дії. Глобальний пошук за назвами тем, допомоги, поясненнями та ключовими словами. Розгорнути допомогу можна в окремій темі або в усіх видимих темах.
- Вибір зберігається локально. Перегляд неповної чернетки доступний. Старий вибір v2 збережений як теми, для яких потрібно явно уточнити допомогу; довільні послуги не підставляються.
- Демокартка показує конкретну допомогу, кілька мов, коротке «Про мене» до 500 символів та списки формату, тривалості, частоти й часу доби.
- У застосунку власне чітке фото стане обов’язковим для публікації за новим рішенням власника. Статичний каталог можна переглядати без завантаження фото; його аналіз тут не імітується.
- Тема означає контекст особистого досвіду; не є підтвердженням професійної кваліфікації.
- Дані й код статичні. Застосунок, його API, чужі профілі, запити й чати не змінюються.
- Нові семантичні ID не підміняють старі Android ID `1.1…8.5`. Міграція й серверна сумісність — окремий етап впровадження після перегляду структури.

`catalog.json` — переносне джерело структури. `build_catalog.py` формує його з авторської пропозиції та `support_options.py`. Усі 144 ID тем збережено; кожна конкретна дія має стабільний ID `<topic>.help.<slug>`. Генератор відхиляє неповне або зайве покриття тем. `index.html`, `style.css`, `app.js` — мобільна й настільна демонстрація.

Шрифти Prata та Manrope завантажуються з Google Fonts; системні резервні шрифти підтримуються. Іншої зовнішньої залежності немає. Сторінка не містить аналітики, секретів, реальних профілів або приватних даних.

Це пропозиція структури, а не завершена міграція Android/API. Зв’язаний план зберігається в neurolutionary/neuro-bot.


Поточний інкремент: [neuro-bot #1002](https://github.com/neurolutionary/neuro-bot/issues/1002). Новий каталог — демонстрація для перегляду, а не доказ доставки змін Android/API.
